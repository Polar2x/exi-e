# Exi-E Discord Bot & Website

A powerful Discord bot connected to a companion website with cool features like user profiles, server stats, and real-time notifications.

## Features

- 🤖 Discord bot with interactive commands
- 🌐 Companion website with user dashboard
- 📊 Server analytics and statistics
- 👤 User profiles and reputation system
- 💬 Real-time chat integration
- 🎮 Fun games and mini-games
- ⚙️ Bot configuration panel

## Project Structure

```
.
├── bot/              # Discord bot source code
├── website/          # Next.js website
├── shared/           # Shared utilities and types
├── docker-compose.yml
└── README.md
```
